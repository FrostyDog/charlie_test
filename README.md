## Number randomizer

Generate 10 random integers between **1 and 10** (inclusive). Duplicates may occur.

If arguments are invalid, the script prints an error message and exits non-zero.

### Run

```bash
# Default: 10 numbers, range 1..10
node randomizer.js

# Custom: <count> <min> <max>
node randomizer.js 5 1 100
```
